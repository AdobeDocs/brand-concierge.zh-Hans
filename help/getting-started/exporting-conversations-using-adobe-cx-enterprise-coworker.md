# 使用Adobe CX Enterprise Coworker导出对话

了解如何使用Adobe Experience Platform查询服务和Adobe CX Enterprise Coworker保存和导出Adobe Brand Concierge对话。 本视频说明如何查找数据集表名称、请求某个日期范围内的对话数据以及在贵组织中使用数据Distiller时下载CSV。

## 此视频面向谁？

* 需要导出Brand Concierge对话数据的开发人员

## 视频内容

* 在Experience Platform中查找对话数据集并复制其表名
* 要求同事从响应表中检索指定日期范围内的数据
* 了解为什么视频中显示的CSV下载需要数据Distiller
* 存储可能包含个人身份信息(PII)的导出时，请遵循您组织的数据处理策略

>[!VIDEO](https://video.tv.adobe.com/v/3504546)

>[!NOTE]
>
> 如果您的组织中不提供Data Distiller，Co-worker将无法创建此视频中显示的CSV下载。 选择[观看查询服务和终端视频](exporting-conversations-using-query-service-and-terminal.md)以了解如何使用“终端”将对话数据导出到CSV文件。

有关文档，请参阅[Brand Concierge帮助](../documentation/overview.md)。
