# 部署礼宾

部署Adobe Brand Concierge后，真正的网站访客便可以使用该功能。 此视频介绍如何配置数据流以跟踪访客参与情况，然后设置表面配置来控制礼宾员在哪些页面和域上显示。

## 此视频面向谁？

* 营销人员将门房部署到其网站
* 提供数据流ID并安装脚本的IT或Web开发团队
* 团队控制门房在其网站上的显示位置

## 视频内容

* 在Adobe Experience Platform中“数据收集”>“数据流”下的何处查找数据流ID
* 如何添加数据流配置并复制生成的安装脚本
* 组件安装与脚本的全页安装选项比较
* 如何通过匹配域和路径（任何、开头为、结尾为、等于）来配置表面规则
