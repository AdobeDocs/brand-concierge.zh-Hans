# 创建您的第一个礼宾

了解如何在几分钟内设置您的第一个Adobe Brand Concierge。 提供您的网站URL，Brand Concierge会自动根据您网站的内容构建入门品牌配置文件和说明，您可以在保存之前查看和调整这些配置文件和说明。 构建礼宾后，在桌面和移动设备上使用示例问题对其进行测试，以了解它如何使用您自己的网站内容做出响应。

## 此视频面向谁？

* Digital Experience Manager
* 营销技术人员
* 客户体验Designer

## 视频内容

* 如何输入您的网站URL以自动填充您的品牌配置文件和建议说明
* 如何在保存之前查看和调整品牌配置文件、说明以及入门提示
* 如何在桌面和移动设备上通过示例问题测试您的礼宾
