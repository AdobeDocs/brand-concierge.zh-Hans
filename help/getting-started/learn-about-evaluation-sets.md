# 了解评估集

评估可告知您Adobe Brand Concierge是否正确回答、是否在范围之内以及是否安全地处理复杂的问题。 本视频介绍了三种评估类型 — 功能、超出范围和保护 — 并演示了如何构建评估集、运行评估集以及在上线之前查看标记的结果。

## 此视频面向谁？

* 准备启动的营销人员和内容所有者
* 在上线之前验证礼宾响应的人
* 负责礼宾质量与安全的团队

## 视频内容

* 三种评估类型：功能、超出范围和保护
* 如何构建评估集 — 人工智能生成的问题或您自己的CSV上传
* 如何运行评估并查看总体分数和标记的问题
* 如何将门房人员的实际响应与每个标记问题的预期响应进行比较
