# 门房的上线清单

使用此核对清单完成启动前准备情况检查，然后再向实际访客提供礼宾。 该清单整合了知识源、礼宾管理、评估和部署工作流中描述的准备标准。

>[!NOTE]
>
>考虑将此核对清单作为独立页面发布。 独立页面可以直接从Launch通信链接并独立于完整文档集引用。

## 如何使用本核对清单

在启动之前完成每个项目，并记录任何需要跟踪的项目的所有者或证据。 除非相应的产品、质量或启动项所有者已审查并接受该风险，否则不要针对未解决的问题继续上线。

## 内容和配置

- [ ] **知识源已完全处理。** 确认所有配置的知识源均已完成处理，**修复问题**&#x200B;中没有未解决的错误。
- [ ] **品牌表达式和品牌配置文件准确。** 审查礼宾员的品牌表达和品牌概况，确保其准确性并与预期体验保持一致。
- [ ] **说明和护栏已批准。** 根据适用的品牌指南查看礼宾说明和护栏。
- [ ] **技能和集成已正确映射。** 确认所有必需的技能均已激活并正确映射到其集成。
- [ ] **视觉样式和聊天组件已批准。** 根据品牌预期审查视觉样式和聊天组件。

## 测试和评估

- [ ] **评估集已创建并运行。** 为每个评估类型至少创建并运行一个评估集：
  - 功能
  - 超出范围
  - 安全防护
- [ ] **已审阅标记的结果。** 在启动前调查并解决标记的评估结果。
- [ ] **实时预览测试已完成。** 使用代表性访客问题测试实时预览中的礼宾员。

## 部署就绪性

- [ ] **数据流ID已配置。** 确认为部署配置了正确的数据流ID。
- [ ] **表面配置已审核。** 验证礼宾是否仅显示在预期页面上。
- [ ] **已安装安装脚本。** 向网站团队提供安装脚本，并确认已成功安装该脚本。
- [ ] **B2B可用性已确认（如果适用）。** 对于B2B礼宾，请确认销售代表日历和实时聊天可用性已配置并可操作。

## 启动后准备工作

- [ ] **Analytics访问权限已确认。** 验证相关利益相关者是否可以访问所需的分析。
- [ ] **已建立审核节奏。** 建立定期流程，以便审查对话记录并在显示时添加新的评估问题。

## 将此核对清单作为发布要求发布之前

>[!IMPORTANT]
>
>此核对清单源自指南中描述的工作流。 它不是正式的产品定义发布入口。 在将其作为正式的上线要求发布之前，根据产品和QA定义的发布标准验证它。
