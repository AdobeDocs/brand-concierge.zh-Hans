# 向组织添加用户

在用户访问Brand Concierge之前，请先将用户添加到Adobe Admin Console中的Adobe Experience Platform组织。

>[!PREREQUISITES]
>
>- 您必须具有组织的管理员访问权限。
>- 用户必须能够单独添加或通过批量用户上传进行添加。

## 添加用户

1. 转到&#x200B;**Admin Console**。
1. 选择&#x200B;**管理**&#x200B;或转到&#x200B;**用户**。
1. 单独添加用户，或通过批量上传添加多个用户。
1. 如果组织中不存在该用户，请选择选项，以在出现提示时将用户添加为新用户。
1. 选择产品配置文件：

   - **Adobe Experience Platform**
   - 默认用户配置文件

1. 选择&#x200B;**保存**。

用户会收到一封电子邮件邀请，确认其访问组织。

>[!IMPORTANT]
>
>组织邀请会授予用户访问组织的权限，但不授予对Brand Concierge的访问权限。 要提供Brand Concierge访问权限，请按照[创建具有Brand Concierge权限的角色](./create-a-role.md)中所述，创建并分配具有Brand Concierge权限的角色。

## 后续步骤

将该用户添加到组织后，创建具有&#x200B;**管理Brand Concierge**&#x200B;权限的角色并将该用户分配给该角色。
