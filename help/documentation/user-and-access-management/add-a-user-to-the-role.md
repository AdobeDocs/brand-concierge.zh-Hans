# 将用户添加到Brand Concierge角色

将用户分配给包含&#x200B;**管理Brand Concierge**&#x200B;权限的角色。 用户还必须具有对Adobe Experience Platform组织的访问权限，然后才能使用Brand Concierge。

## 先决条件

* 用户已添加到Adobe Experience Platform组织。 有关更多信息，请参阅“将用户添加到组织”（链接）。
* 已创建包含&#x200B;**管理Brand Concierge**&#x200B;权限的角色。 有关更多信息，请参阅“创建具有Brand Concierge权限的角色”（链接）。

## 从角色添加用户

1. 在Adobe Experience Platform中，打开&#x200B;**权限**。
2. 打开为访问Brand Concierge而创建的角色。
3. 选择&#x200B;**用户**&#x200B;选项卡。
4. 搜索用户并将用户添加到该角色。
5. 如果出现提示，请保存分配。

## 从用户记录添加角色

您还可以从用户记录中分配角色：

1. 打开用户的记录。
2. 选择&#x200B;**添加角色**。
3. 搜索Brand Concierge角色。
4. 选择角色并保存分配。

## 验证访问权限

在组织邀请和角色分配完成后，用户可以：

* 登录到`experienceplatform.adobe.com`。
* 查看他们可以访问的组织。
* 打开&#x200B;**Brand Concierge**。
* 查看通过角色授予的一个或多个沙盒。

在一个沙盒中，用户可以创建多个礼宾。
