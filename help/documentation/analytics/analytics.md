# 分析门房表现

**适用对象：**&#x200B;使用自助式体验的营销人员。 在部署礼宾后无需进行设置。

**建议的节奏：**&#x200B;根据需要查看分析。 每周入住是一个合理的起点。

Analytics可帮助您了解访客如何与实时门房互动。 部署后，**Analytics**&#x200B;选项卡会自动显示对话量度，并提供对个人成绩单和更详细Customer Journey Analytics报告的访问权限。

## 查看分析

1. 打开门房并选择&#x200B;**Analytics**&#x200B;选项卡。

1. 为要复核的期间设置日期范围。

1. （可选）按对话类型筛选结果。

Analytics选项卡会自动显示以下量度：

| 量度 | 描述 |
|---|---|
| 对话 | 所选时段内的对话数。 |
| 参与访客 | 与门房接触的访客数量。 |
| 正面情绪 | 对话中识别出的积极情绪的数量。 |
| 每个对话的消息数 | 对话中交换的平均消息数。 |

>[!NOTE]
>
>在部署礼宾后，无需配置即可查看这些量度。

## 查看对话记录

通过对话记录，您可以查看访客的询问内容以及门房的回应方式。

1. 在Analytics选项卡中，选择一个对话。

1. 阅读完整记录。

1. 查看访客是选择对各个答案进行竖起还是竖起或下拉评级。

每个对话都有一个唯一的对话ID。 如果您的实施支持该工作流，请使用此ID将转录与其他系统中的记录相匹配。

### 将对话添加到评估集

如果访客提出对未来测试有用的问题，请将其直接添加到成绩单中的评估集。

1. 打开对话记录。

1. 选择&#x200B;**添加到评估**。

添加真正的访客问题有助于使评估集以访客实际提出的问题为基础。 有关评估集的详细信息，请参阅[评估门房](../evaluation/evaluation.md)。

>[!TIP]
>
>定期审查成绩单并添加有代表性的问题，而不仅仅是收到负面反馈的问题，以帮助保持平衡的评价集。

## 打开Customer Journey Analytics报表

选择&#x200B;**查看报表**&#x200B;以在Adobe Customer Journey Analytics (CJA)中打开更详细的仪表板。 仪表板是自动配置的，不需要进行其他配置。

CJA功能板包括：

- 每周对话趋势。
- 重复参与，包括每个人的对话。
- 每个对话的消息数。
- 访客反馈趋势。
- 访客意图。
- 访客情绪和色调。
- 对话期间提出的礼宾推荐。

使用功能板检查一段时间的趋势，并识别访客参与度、反馈、意图和情绪方面的变化。

## 导出对话

源资料将会话ID标识为将成绩单与其他系统中的记录进行匹配的一种方式，但它没有记录导出机制。

>[!IMPORTANT]
>
>请勿将对话ID视为导出工作流。 在记录如何导出对话或成绩单之前，需要产品或工程部门的专用演练。
