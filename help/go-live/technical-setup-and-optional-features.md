# 技术设置和可选功能

为Adobe Brand Concierge准备网站，然后选择支持访客体验的可选功能。 本视频介绍部署要求、将礼宾员添加到网站的方法以及与Meeting Booking、Live Chat和Marketo Engage的集成。

## 此视频面向谁？

* 网站开发人员和管理员
* 营销技术团队

## 视频内容

* 部署要求：标记管理系统或手动添加的代码段、目标页面、Adobe Experience Platform沙盒和IMS组织以及数据流
* 使用标签管理器将礼宾添加到您的网站或直接添加到您的代码库中
* 设置与代表的会议预订、可用性和计划详细信息
* 通过代表可用性、访客触发器和会议预订回退启用实时聊天
* 连接Marketo Engage以接收商机和活动，并具有管理员访问权限和功能标记
